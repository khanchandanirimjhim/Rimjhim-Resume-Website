# Rimjhim Khanchandani — Resume Portfolio

## Files
- `index.html` — resume website content and navigation
- `style.css` — responsive styling, colour palette, layout and typography

## Preview locally
1. Extract this folder.
2. Open `index.html` in a browser.
3. Keep `index.html` and `style.css` in the same folder.

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload `index.html` and `style.css` to the repository root (or replace the old versions).
3. Commit the changes.
4. In the repository, open **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**.
6. Select your main branch and `/ (root)`, then Save.
7. Wait for GitHub Pages to publish. Copy the website URL shown in Settings → Pages.

## Assignment PDF
Use the accompanying PDF template as a starting point. Replace the placeholders for your roll number, live website URL and GitHub repository URL after publishing.

Note: Google Fonts requires an internet connection. The website includes common fallback fonts.
